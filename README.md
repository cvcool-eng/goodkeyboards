# GoodKeyboards

**Visit the site: https://cvcool-eng.github.io/goodkeyboards/**

GoodKeyboards is a showcase of the best gaming keyboards on the market, sorted into simple categories so you can find the keyboard that fits you:

- [60% Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/60/)
- [65% Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/65/)
- [75% Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/75/)
- [Typing Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/typing/)
- [Thock Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/thock/)
- [Quiet Keyboards](https://cvcool-eng.github.io/goodkeyboards/category/quiet/)
- [Budget Keyboards (under $60)](https://cvcool-eng.github.io/goodkeyboards/category/budget/)

Each keyboard has its own page with specs, a YouTube review, and links to stores like Amazon and eBay.
